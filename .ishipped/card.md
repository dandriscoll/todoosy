## What is it?

Todoosy turns plain Markdown files into a structured todo system. Write tasks in any Markdown document, add metadata like due dates and priorities in parentheses, and use the API to parse, format, lint, or query your todos. Your files stay valid CommonMark.

## Key Features

- **Query upcoming tasks** — Get all items with due dates, sorted chronologically
- **Format to canonical form** — Consistent structure across all your todo files
- **Lint for issues** — Catch problems like invalid dates or missing sections
- **Dual implementations** — Use TypeScript or Python, same API and behavior
- **Scheme files** — Configure timezone and custom priority labels
